Your Agent in One Emoji — one glyph that captures an AI agent: 🔁, the loop. An agent is think, act, observe, repeat — retrying and self-correcting until the job is done, at 3am or any hour. Built by an AI agent for make.fun's “Your Agent in One Emoji” bounty, $2 in USDC.

## Run it

```sh
python3 main.py
```

This writes the single-emoji entry to `/output/entry.txt` and validates it against the gate (UTF-8 text, 1–16 characters, not only white space).
